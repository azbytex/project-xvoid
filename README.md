## ◈ About

**PROJECT-XVOID** is an all-in-one developer workspace and cyber intelligence suite built for **education, research, experimentation, and authorized security testing.**

Designed with a calm dark digital studio aesthetic, high-contrast typography, and lightweight vanilla architecture, it delivers maximum performance without bloated client frameworks.

### ⚡ Modules

| | Module | Purpose |
|---|---|---|
| ◈ | **NIK Intel** | NIK structure & regional analysis |
| ◈ | **Phone Intel** | International phone metadata & temp SMS inbox |
| ◈ | **Sherlock OSINT** | Multi-platform username reconnaissance |
| ◈ | **Network Recon** | Subdomain discovery (crt.sh / HackerTarget) & Port scanning |
| ◈ | **Strix Engine** | Automated HTTP security audit & pentesting |
| ◈ | **XVoid AI** | Integrated multi-model AI coding & security assistant |
| ◈ | **Dev Suite** | GitHub repo scanner, Web to APK, Web to ZIP |
| ◈ | **Dashboard** | Unified quiet workspace interface |

---

## 🎨 Design Philosophy

- **Zero-Slop UI**: 100% SVG-first iconography. No childish emojis or distracting neon glows.
- **High-Contrast Dark Studio**: Curated `#0D0D12` base surfaces with `#E8E7E3` primary text and `#A8A1FF` focus accents.
- **Keyboard-First Navigation**: Accessible tabindexing and keyboard shortcut support across all home cards and modal views.
- **Lightweight & Fast**: Zero client-side framework bloat. Pure semantic HTML5, CSS3, and modern JavaScript.

## 🚀 Quick Start

### Prerequisites
- Python 3.10+
- Modern web browser (Chrome, Firefox, Edge, Safari)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/azbytex/project-xvoid.git
   cd project-xvoid
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the local server:**
   ```bash
   python server.py
   ```

4. **Access the workspace:**
   Open your browser and navigate to:
   ```
   http://127.0.0.1:3000
   ```

---

## ☁️ Deployment (Vercel Serverless)

Project-XVoid includes native Vercel configuration (`vercel.json` and `api/index.py`).

1. Install the Vercel CLI:
   ```bash
   npm install -g vercel
   ```
2. Deploy directly:
   ```bash
   vercel
   ```
